# Редизайн G: светло-серый + графит с мятой

Направление утверждено Piotr 01.11.2026. Здесь лежит референс для вёрстки. Это не код сайта.

- `index.html` — главная.
- `nugaros-skausmas.html` — шаблон страницы проблемы.

Открываются прямо в браузере: фото берутся из `public/`, шрифт — из Google Fonts. Ширина 1280 и 375 px.
Блок «Kur skauda?» в макете сделан на радиокнопках. На сайте его нужно сделать на React-состоянии (см. ниже).

## Токены (в `@theme`, `src/app/globals.css`)

| Роль | Цвет | Где |
| --- | --- | --- |
| ground | `#ECEDEB` | фон страницы, шапка, первый экран, «Pirmasis vizitas», строки «Kur skauda?» |
| ground-hover | `#E2E4E1` | hover строк «Kur skauda?» на десктопе |
| paper | `#F7F7F6` | чередующиеся светлые секции: «Kur skauda?», услуги, отзывы |
| ink | `#2B2C2B` | основной текст и заголовки на светлом |
| graphite | `#5F605F` | тёмные блоки (специалисты, запись и футер), кнопки на светлом, второстепенный текст |
| mint | `#9DD0CB` | заголовки на графите, кнопки на графите (текст на них — ink), круг и полоса первого экрана, точки-маркеры |
| mint-light | `#B5DDD8` | hover мятной кнопки |
| on-dark | `#E9EBEA` | второстепенный текст на графите |
| focus | `#437571` | `:focus-visible` |

Правила:
- Мятный текст — только крупный и только на графите. На светлом фоне мятным текст не набирать.
- Белый текст на `#5F605F` даёт 6,3:1. Ink на мяте — 8,2:1.
- Секции разделяются сменой фона, без линий и теней.

**Шрифт:** Onest уже подключён.

| Роль | Размер | Начертание |
| --- | --- | --- |
| h1 | `clamp(36px, 4.6vw, 64px)` | 500, tracking −0.025em, leading 1.02 |
| h2 | `clamp(30px, 2.9vw, 42px)` | 500 |
| h3 и фразы | `clamp(26px, 2.4vw, 34px)` | — |
| lead | 20px, leading 1.5 | — |
| текст | 18px | — |
| мелкий | 16px | — |

Шкала уменьшена 01.11.2026 (главная компактнее), `index.html` показывает прежние размеры. Других размеров не вводить. На телефоне h1 — `clamp(36px, 10vw, 46px)`, фразы — 22px, lead первого экрана (`lead-m`) — 18px, leading 1.5.

**Кнопки:** pill, `border-radius: 999px`, высота 52px (в шапке 46px).
- На светлом фоне: фон graphite, белый текст, hover ink.
- На графите: фон mint, текст ink.

**Ссылки-действия:** подчёркивание 2px мятой, offset 5px.

**Отступы:** сверху и снизу секции 96px на десктопе и 64px на телефоне. Поля 32 / 20px. Контейнер — 1376px.
